# AETRAM – Women Welfare Assistant

AETRAM is a multilingual, voice-first web platform designed to help women discover relevant government welfare schemes through simple language and smart eligibility guidance.

## Features

- 🎤 Voice-based scheme discovery
- 🧠 Smart Eligibility Checker
- 🌐 Tamil, English, Hindi, Marathi, Kannada and Telugu
- 📄 Documents Required section
- 🤖 Interactive chatbot
- 🔊 Voice-based scheme explanations
- ♿ Accessibility-focused interface
- 📱 Responsive web design

## Technologies

- HTML5
- CSS3
- JavaScript
- Web Speech API
- GitHub Pages

## Deployment

This project is deployed using GitHub Pages.

## Disclaimer

AETRAM provides informational guidance about government schemes. Users should verify eligibility and application requirements through official government sources.
